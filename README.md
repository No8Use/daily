# Daily 🗓️

Локальное (offline-first) Flutter-приложение для ежедневного трекинга привычек, задач, заметок и дневных отзывов с интерактивным Heatmap в стиле GitHub.

---

## 🚀 Основные возможности

1. **Heatmap активности** — визуализация выполненных привычек и задач в формате патча активности.
   - Переключение между режимами: *Только привычки* и *Все задачи*.
   - Интерактивный тап по ячейке дня открывает подробную карточку дня (`DayScreen`).
2. **Задачи (Tasks)** — задачи, привязанные к конкретным датам, с возможностью отметки выполнения.
3. **Привычки (Habits)** — повторяющиеся ежедневные ритуалы.
   - Поддержка мягкого удаления (soft delete / отмена) для сохранения истории в Heatmap.
   - Возможность восстановления отменённых привычек.
4. **Заметки (Notes)** — удобный журнал с фильтрами и поддержкой планирования локальных уведомлений (`needCheckDate`).
5. **Дневной отзыв (Daily Review)** — оценка дня по шкале от 1 до 10 с текстом отзыва.
   - **Ограничение:** редактирование отзыва доступно только в текущий день.
6. **Экспорт и Импорт данных (Backup)** — полное сохранение структуры базы данных в JSON-файл и его восстановление с режимами `Merge` (объединение) или `Replace` (полная перезапись).

## 📦 Сборка и запуск проекта

### 1. Установка зависимостей
```bash
flutter pub get
```

### 2. Генерация Drift базы данных (`build_runner`)
Для генерации файла `lib/data/database/app_database.g.dart` выполните команду:
```bash
dart run build_runner build --delete-conflicting-outputs
```

> **Примечание:** если у вас настроена FVM или системный путь Flutter:
> ```bash
> flutter pub run build_runner build --delete-conflicting-outputs
> ```

### 3. Запуск приложения
```bash
flutter run
```

## 💾 Как работает Экспорт / Импорт (Backup)

### Экспорт
1. Нажмите меню `⋮` в верхнем углу `HomeScreen` -> **Экспорт данных**.
2. Приложение сформирует дамп всех таблиц в файл `daily_backup_YYYY-MM-DD_HH-mm.json` во временную директорию.
3. Откроется системный диалог шэринга (`share_plus`) для сохранения или отправки файла.

### Импорт
1. Нажмите меню `⋮` -> **Импорт данных**.
2. Выберите файл резервной копии `.json` через встроенный проводник (`file_picker`).
3. Выберите режим:
   - **Объединить (Merge):** сохраняет текущие данные и перезаписывает/добавляет записи из бэкапа по совпадению ID.
   - **Заменить (Replace):** полностью очищает локальную БД и загружает данные из бэкапа.
4. После успешного импорта экран автоматически обновит данные всех Cubit'ов.

## ℹ️ Известные особенности и ограничения

- **Редактирование отзывов:** В соответствии с бизнес-логикой приложения, отзывы за прошедшие дни доступны только для просмотра в карточке дня. Создать или изменить отзыв можно только за текущий день (`date == today`).
- **Уведомления:** Для корректной работы точных локальных напоминаний на Android 13+ требуется выдать разрешение на отправку уведомлений и точные будильники (разрешения уже добавлены в `AndroidManifest.xml`).
